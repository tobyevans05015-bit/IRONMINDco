IRON MIND COLLECTIVE — MULTI-PAGE WEBSITE

FILES
- index.html          Home / main landing page
- philosophy.html     Brand philosophy, principles and roadmap
- foundations.html    Three foundations: body, shadow and identity
- guides.html         Digital guides and tools
- collective.html     Community vision and social links
- assets/site.css     Shared styling and responsive layout
- assets/site.js      Mobile navigation and reveal animations

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. Use the top navigation to move between the separate pages.

HOW TO PUBLISH
Upload the contents of this folder (not the ZIP itself) to your hosting provider, keeping the assets folder alongside the HTML files. The site uses relative links, so the page navigation will work when the folder structure is preserved.

NOTES
- Existing Gumroad product URLs and the Shadow Lab / Iron Lifts URLs were carried over from the current site.
- The site is front-end only. No contact form, member login, checkout backend or booking system has been added.
- Google Fonts are loaded online; the layout falls back to system fonts if unavailable.
- Coaching and community offerings are described as in development rather than as currently purchasable services.
